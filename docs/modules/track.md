# 예측 성적표 — 방법론

## 과거 검증
- **인구 추계 엔진**: 2020년 말 인구와 2017→2020년 변화율만으로 2021~2025년 시군구 총인구·65세 이상·0~9세를 예측해 실제 주민등록 인구와 비교합니다(출산율은 2020년 수준 고정). 비교 기준은 "2020년 인구 그대로"입니다.
- **학교·출생·대학**: 각 모듈의 과거 검증을 모읍니다.
- **참고**: 통계청 장래인구추계(2022년 기준) 출생아와 실제 출생아를 비교합니다.

## 실시간 장부
ETL을 돌릴 때마다 아직 실측이 없는 해의 예측(올해·내년 출생아, 올해 합계출산율, 내년 말 인구, 내년 초등학생, 내년 대학 입학자)을 `src/data/track.json`의 `ledger`에 적습니다. 같은 대상·같은 근거 자료로는 한 번만 적고, 근거 자료가 새로 나오면 새 줄을 추가합니다. 실측이 나오면 오차와 범위 적중 여부를 채웁니다. 장부는 git 이력에 남습니다.

## 한계
과거 검증은 지금 정한 방법을 과거에 적용한 것이라 "그때 실제로 이렇게 예측했다"는 뜻은 아닙니다. 이를 보완하는 것이 실시간 장부입니다.
