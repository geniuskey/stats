# 대한민국의 미래 — 방법론

## 결합 데이터
- 주민등록인구 1세별 2015~2025 (`DT_1B04006`): 내국인 기준
- 인구동향 출생아 수·합계출산율 (`DT_1B81A23`)
- 장래인구추계 2022년 기준: 시나리오별 출생아·가임여성·주요 지표 (`DT_1BPA001`, `DT_1BPA002`, `DT_1BPA004`, `DT_1BPA402`, `DT_1BPA403`)

## 계산
- 시군구 229곳을 각각 추계한 뒤 합산해 전국·시도 값을 구합니다.
- 출산율 지수 = 시나리오별 (출생아 ÷ 20~44세 여성) ÷ 2025년 값. 2025년 실제 출생 수준에 곱합니다.
- "현실은 어느 시나리오인가"는 최근 연도 실제 출생아와 각 시나리오 출생아의 차이로 판정합니다.

## 한계
- 외국인이 빠져 공식 추계보다 총인구가 낮습니다.
- 기대수명 개선을 따로 모형화하지 않아 고령 인구가 과소추계될 수 있습니다.
