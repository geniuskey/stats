# 소멸하는 상권, 성장하는 상권 — 방법론

- 빌더: `etl/build_commerce.py` → `src/data/commerce.json`
- 실행: `cd etl && uv run --python 3.12 python build_commerce.py [-v]` (인구는 `run_all.population()` 캐시 사용)
- 상권 범위: 도매 및 소매업(G) + 숙박 및 음식점업(I), 분석 단위는 시·군·자치구(2025년 말 행정구역, 229개)

## 방법

상권의 '현재 체력'과 '미래 수요'를 한 지표로 결합했습니다. 현재 체력은 고용노동부 사업체노동실태현황의 상권 사업체·종사자 수 연평균 증감률(2020→2024)과, 통계청 기업생멸행정통계의 순진입률(신생률 − 소멸률, 2022~2024 평균)로 측정합니다. 미래 수요는 주민등록인구 기반 자체 소지역 추계(중위)의 소비인구(20~64세) 2025→2030 변화와, 최근 3년 20~39세 순이동률(인구 1천 명당)로 측정합니다.

다섯 요소는 전국 시군구 분포에서 표준화(z, ±3 절단)한 뒤 가중합합니다(사업체 20%, 종사자 20%, 순진입 20%, 소비인구 25%, 청년 순이동 15%). **상권 활력 지수 = 50 + 15 × 가중 z** 이며 0~100으로 자릅니다. 50은 전국 평균 수준입니다.

분류 기준은 공개된 임계값을 따릅니다. **성장**은 지수 58 이상, **정체**는 42~58, **위축**은 42 미만입니다. **소멸위험**은 2035년 소비인구가 20% 이상 줄고 최근 순진입률이 0 이하인 지역이며, 지수와 관계없이 우선 적용합니다. 별도의 조기 신호인 **점포 과잉**은 최근 사업체가 늘었는데 2035년 소비인구가 20% 이상 줄어드는 지역에 붙입니다. 점포 수가 유지된다고 가정할 때 점포 1곳당 수요가 감소할 폭(`demandPerStore2035`)과 2035년 소비인구 1천 명당 점포 수(`storesPer1k2035`)도 함께 제공합니다.

「우리 동네의 미래」용 보조 시계열(`dongne`)도 함께 담았습니다. 전 산업 사업체·종사자 수, 연간 순이동(전체, 20~39세), 주민등록 세대수, 주택 수, 빈집 수와 빈집률입니다.

## 한계

- 사업체노동실태현황은 2019→2020 사이 전국 상권 사업체가 89.8만 → 71.8만으로 꺾여 수준이 꺾입니다(조사 체계 변경 또는 코로나19 영향으로 추정, 원인 미확인). 그래서 증감률은 2020년부터 계산하며, 저점 기준이라 절대값이 높게 나옵니다. 지수는 상대 비교(z)라 영향이 작습니다.
- 기업생멸의 '기업'은 사업체(점포)와 단위가 다르고, 최신 연도 소멸 기업은 1년 늦게 확정됩니다.
- 유동인구·카드매출 같은 상권 내부 자료는 KOSIS에 없습니다. 이 지표는 시군구 단위의 구조적 신호이며, 골목 단위 판단에는 쓸 수 없습니다.
- 소비인구는 주민등록(내국인) 기준이라 관광·통근 수요를 반영하지 않습니다. 관광지(예: 부산 강서구, 신안군)는 점포 밀도가 높게 나옵니다.
- 일반구(수원 장안구 등)는 상위 시에 합산되며, 원천 표의 일반구 행은 무시합니다.
