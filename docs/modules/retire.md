# 은퇴 후 대한민국 — 방법론

생성: `cd etl && uv run --python 3.12 python build_retire.py` → `src/data/retire.json`

## 방법

**필요 노후자금.** 생활비 기준은 국민노후보장패널의 '개인 기준 적정 노후생활비'입니다. 조사 연도 가격으로 된 금액을 소비자물가지수로 최신 연도 가격까지 올린 뒤, 완전생명표의 은퇴 나이 기대여명을 곱합니다. 결과는 오늘 가격(실질) 기준입니다. 수익률과 물가가 같다면 명목 총액도 같습니다. **연금 공백**은 적정생활비에서 65세 이상 연금 수급자의 월평균 수급액(모든 연금 합산)을 뺀 금액에 같은 기간을 곱해 구합니다.

**고령가구 체감물가.** 지출목적 12개 대분류의 10년 연평균 상승률을 가구 유형별 지출 비중으로 가중합니다. 비중은 65세 이상 가구주 가구와 전체 가구 각각의 가계동향조사 소비지출에서 가져옵니다. 고령가구는 식료품과 보건 비중이 높아서 같은 물가 속에서도 상승률을 다르게 체감합니다.

**자금 소진 나이.** 실질 기준 연 단위 시뮬레이션입니다. 매년 잔고에 실질수익률(명목수익률 − 물가)을 적용하고, 생활비와 연금의 차이(월 × 12)를 인출합니다. 잔고가 0 아래로 내려가는 나이를 소진 나이로 봅니다. 미리 계산한 격자(자산 1·2·3·5억 원 × 실질수익률 0~3%)를 함께 제공하고, `calculator.defaults`로 브라우저 계산기를 초기화합니다.

**부양 구조.** 주민등록 1세별 인구를 Hamilton-Perry 방식으로 추계한 값(출산율 저위·중위·고위)에서 20~64세 인구를 65세 이상 인구로 나눕니다. 2035년 연금 수급자 수는 65세 이상 추계 인구에 최신 수급률을 곱한 근사치입니다.

## 주의

- 연금 평균액은 수급자 평균이고 평균은 소수의 고액 수급자에게 끌려 올라갑니다. 중위값(49.7만 원)과 함께 봐야 합니다. 부부가 함께 받는 경우는 반영되지 않습니다.
- 적정생활비는 응답자의 인식 조사 결과입니다. 의료·요양비가 크게 드는 사건은 기대여명 평균에 반영되지 않습니다.
- 생명표는 기간생명표라서 앞으로의 수명 개선이 빠져 있습니다. 실제 기대여명은 이보다 길 가능성이 높습니다(장래 생명표 참고).
- 가계동향 65세 이상 가구의 평균 가구원 수는 약 1.8명이라 1인 기준 생활비와 단순 비교할 수 없습니다.
- 국민연금 소득대체율과 개혁안 변화는 반영하지 않았습니다.
